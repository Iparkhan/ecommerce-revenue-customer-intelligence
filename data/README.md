# Dataset

We will use **Online Retail II** from the UCI Machine Learning Repository.

- Official source: https://archive.ics.uci.edu/dataset/502/online_retail%2Bii
- Citation: Chen, D. (2012). Online Retail II. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
- Licence: CC BY 4.0 (credit the source in project materials)
- Contents: 1,067,371 transaction lines from a UK online retailer, Dec 2009–Dec 2011.
- Original workbook: `online_retail_II.xlsx` (about 43.5 MB)

Download the workbook from the official UCI page and place it in this folder. The raw file is excluded from Git by `.gitignore`.
